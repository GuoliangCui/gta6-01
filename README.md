**Neon Harbor** — a top-down open-world action game in pure Canvas 2D with zero dependencies. Explore a procedurally built harbor city on foot or by car: steal cars, dodge or fight the police under a 1–5 star wanted system, and work through Marina's three-mission storyline (a timed delivery, a forced-two-stars car theft, and a dockside shootout). Lane-following traffic, pedestrians, hitscan combat, an arrest meter, a live minimap HUD, localStorage saves, and fully synthesized WebAudio sound — all running on a deterministic seeded simulation, split by responsibility across 18 small modules in `game/src/`.

Controls: WASD move / drive · Shift run · F enter / exit car · mouse aim, click shoot · R reload · E talk / advance dialogue · Esc pause · N new game (title screen).
